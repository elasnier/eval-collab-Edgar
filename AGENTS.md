# AGENTS.md

## Projet
Site vitrine "Squishy Dumplings".
Structure : Maquette statique composée d'un unique fichier `index.html` contenant le HTML sémantique et le CSS intégré.

## Commandes
- Visualiser : double-cliquer sur `index.html` (ou utiliser Live Server)
- Aucun processus de build (pas de `npm install` ni `npm run dev`)

## Conventions
- Conventional Commits obligatoires (ex: `docs(readme): ajoute les badges`)
- Les branches doivent être nommées de manière descriptive (ex: `docs/n2-documentation`)
- Code et documentation rédigés en français par défaut
- CSS natif avec variables (`:root`) pour les couleurs

## Interdits
- Ne jamais ajouter de frameworks JavaScript (React, Vue, Angular)
- Ne jamais utiliser de bibliothèques CSS utilitaires externes (Tailwind CSS, Bootstrap)
- Ne pas introduire de backend ou de dépendances serveur
